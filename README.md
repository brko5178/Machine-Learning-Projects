# Machine-Learning-Projects
This repository contains two machine learning projects that I made. The first is [Glioma](https://www.mayoclinic.org/diseases-conditions/glioma/symptoms-causes/syc-20350251) classification which compares the performance of several supervised learning models in thier ability to classify a glioma as major or minor given demographic and genetic information of patients.

The second project, Xrays,  is a notebook detailing the creation of a neural network with the intent to be used to diagnose patients with [Tuberculosis](https://www.mayoclinic.org/diseases-conditions/tuberculosis/symptoms-causes/syc-20351250) or not based on their lung x-rays.

I enjoy these projects as they allow me to combine both my interest in machine learning with healthcare which is something I am passionate about as well. They also use a variety of machine learning models and techniques and have exciting possible uses!
